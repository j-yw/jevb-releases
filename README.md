# jevb releases

Release downloads for jevb. The source is private.

Releases are published here starting with the next jevb version. To install on macOS or Linux:

```bash
brew install j-yw/tap/jevb
```

Or download the `.deb`, `.rpm`, `.apk` or `.pkg.tar.zst` package from the latest release and install it with your package manager. On Arch, `pacman -U` accepts the package's download URL directly. `SHA256SUMS` lists the checksums.
