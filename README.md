# jevb releases

Release downloads for jevb. The source is private.

Releases are published here starting with the next jevb version. To install:

```bash
brew install j-yw/tap/jevb   # macOS and Linux
yay -S jevb-bin              # Arch Linux, from the AUR
```

Or download the `.deb`, `.rpm`, `.apk` or `.pkg.tar.zst` package from the latest release and install it with your package manager. `SHA256SUMS` lists the checksums.
