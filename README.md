# jevb releases

Release downloads for jevb. The source is private.

To install on macOS or Linux:

```bash
brew install j-yw/tap/jevb
```

Or download the `.deb`, `.rpm`, `.apk` or `.pkg.tar.zst` package from the [latest release](https://github.com/j-yw/jevb-releases/releases/latest) and install the downloaded file with your package manager, for example `sudo pacman -U ./jevb-0.5.0-1-x86_64.pkg.tar.zst` on Arch. The packages are not signed, so pacman refuses them by URL. `SHA256SUMS` lists the checksums.
